# Happy Dictionary (C++)

A robust, console-based Dictionary application developed in C++ that allows users to manage words and their definitions with persistent file storage.

## Features
- **Add Words**: Easily add new word-definition pairs.
- **Search**: Quickly find the definition of any word.
- **View All**: Display the complete list of saved entries.
- **Sort**: Alphabetically organize your dictionary.
- **Delete**: Remove unwanted entries.
- **Persistence**: Automatically saves and loads your dictionary data from a `dictionary.txt` file.

## How to Run
1. Ensure you have a C++ compiler (like `g++`) installed.
2. Clone this repository to your local machine.
3. Open the terminal in the project folder.
4. Compile the program:
   ```bash
   g++ -o dictionary main.cpp
